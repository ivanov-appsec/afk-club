# AFK Club

Неофициальный демонстрационный прототип сайта компьютерного клуба AFK в Йошкар-Оле.

**Демо:** <https://ivanov-appsec.github.io/afk-club/>

## Возможности прототипа

- Главный экран и навигация по секциям; вместо фотографии клуба используется CSS-заглушка.
- Тарифы с переключением продолжительности и отдельным блоком школьного тарифа.
- Игровые зоны и характеристики компьютеров.
- Контактная информация: адрес и ссылка на TikTok-профиль клуба.

## Технологии

React, TypeScript, Vite, CSS, npm и GitHub Actions.

## Локальный запуск и проверки

Требуется установленный Node.js и npm.

```bash
npm ci
npm run dev
```

Другие доступные команды:

```bash
npm run lint     # проверка кода
npm run build    # production-сборка в dist/
npm run preview  # локальный просмотр production-сборки
```

## Публикация

Workflow GitHub Actions собирает и публикует `dist/` на GitHub Pages при push в ветку `master` или при ручном запуске (`workflow_dispatch`). Перед загрузкой он устанавливает зависимости и выполняет lint и production-сборку.

## Важно

Это демонстрационный прототип, а не подтверждённый официальный сайт клуба. Перед его официальным использованием владелец должен проверить актуальность цен и условий тарифов, характеристик оборудования, адреса и ссылки на социальные сети.
