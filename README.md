# AFK Club frontend

Основа frontend-проекта на React, TypeScript и Vite. Дизайн и содержимое сайта пока не добавлены.

## Установка

```bash
npm install
```

## Режим разработки

```bash
npm run dev
```

## Production-сборка

```bash
npm run build
```

Предварительный просмотр собранного проекта:

```bash
npm run preview
```

Проверка распространённых ошибок:

```bash
npm run lint
```
